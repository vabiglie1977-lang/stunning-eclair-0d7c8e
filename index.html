Términos y Privacidad

1. Sobre Fresco

Fresco es una aplicación de gestión de despensa doméstica, diseñada para uso personal y familiar. Al utilizarla, aceptas estos términos.

2. Privacidad y Datos

Tu privacidad es importante. La aplicación funciona de la siguiente manera:

  • Datos Locales: La información se guarda en la memoria de tu propio dispositivo (navegador).
  • Sincronización en la Nube: Si la función está activa, los datos se sincronizan en una base de datos privada (Firebase) asociada a tu código familiar.
  • No compartimos tus datos: No recolectamos, vendemos ni compartimos tu información personal con terceros.

3. Uso de Servicios de Terceros

  • OpenFoodFacts: Para buscar información de productos al escanear el código de barras.
  • TheMealDB, Google Translate y MyMemory: Para buscar recetas de cocina y traducirlas automáticamente.
  • Firebase (Google): Para guardar y sincronizar tu lista de compras y despensa.
  • Pollinations AI: Para generar recetas inteligentes basadas en tu stock.

4. Límite de Responsabilidad

  • Pérdida de datos (se recomienda usar "Exportar" en Ajustes).
  • Alimentos vencidos, ya que las fechas dependen del usuario.
  • Información nutricional incorrecta proveniente de bases de datos externas.
  • Recetas generadas por IA: verificá siempre los ingredientes antes de cocinar.

5. Seguridad

Te recomendamos no compartir tu base de datos de Firebase ni las reglas de configuración.
